# Experiment Guide: Main Experiment and Nine Add-ons

For every experiment this page lists its **purpose, data/models, command, outputs and paper item**.
Run all commands from the repository root. 

## 0. Common conventions

| Item | Convention |
|---|---|
| Tasks | `classification` (four-class CIFAR-10), `regression` (UTKFace), `classification_full` (ten-class CIFAR-10) |
| Networks | `VGG-11`, `Res-18`, `ViT-8`, `Mix-8` |
| Probes | diagonal MD-LP; 4/10 one-vs-rest facets for classification, 9 age-quantile facets for regression |
| Evaluation | in-sample 20k training samples; only samples with “last-layer probe prediction = network prediction” are kept; `s=0.2` |
| Noise | `gauss a=0.2`, `salt n=64`, `move degree=15`, `occ v=192`, PGD `eps=2.0/alpha=0.2/steps=20`; ten repeats each |
| Uncertainty | across-repeat std `s` (ddof=0), `SE=s/sqrt(n-1)`, tie threshold `2.77·SE` |

Seeds live in `src/common/seeding.py`; paths and the model registry in `src/common/config.py`.
Concrete values and derivation rules are in [reproduction.md](reproduction.md) and `tools/seeds.json`.

## 1. Main experiment

The main experiment has five stages and corresponds to Section 5, Tables 3–9 and Figures 2–8.

### 1.1 Training

```bash
python -m src.pipelines.run_train --task classification --model VGG-11
python -m src.pipelines.run_train --task regression --model VGG-11
python -m src.pipelines.run_train --task classification_full --model VGG-11
python -m src.pipelines.run_train --task classification --model VGG-11 --exp noise --noise-aug
```

- Code: `src/models/network.py`, `src/models/trainer.py`, `src/pipelines/run_train.py`.
- Output: `model/<task>/clean/<Model>.h5` or `model/<task>/noise_trained/<Model>.h5`.
- Settings: 200 epochs, batch 128, 5-epoch linear warm-up + cosine decay, mixup 0.2 (0.05 for regression).

### 1.2 Noise generation

```bash
python -m src.noise.build_noise --task classification --what all --repeats 10
python -m src.noise.build_noise --task classification --what perturb --repeats 10
python -m src.noise.build_noise --task classification --what attack --repeats 10 --model VGG-11
```

- Code: `src/noise/perturbations.py`, `src/noise/attacks.py`, `src/noise/build_noise.py`.
- Output: `dataset/noise/{gauss,salt,move,occ}/<task>/<repeat>.npy` and
  `dataset/noise/attack/<task>/<repeat>/<Model>_pgd.npy`; group seeds under `dataset/noise/_seeds/<task>/`.
- PGD samples are model-specific (white-box attack).

### 1.3 Probes and criteria

```bash
python -m src.pipelines.run_probe_eval --task classification --model VGG-11 --exp clean
```

- Code: `src/probe/weights.py`, `src/probe/streaming.py`, `src/probe/evaluate.py`,
  `src/pipelines/run_probe_eval.py`.
- Output:
  - `result/probe/clean/<task>/<Model>/<layer>_{w,b}.npy`, `probe_acc.pkl`;
  - `result/criteria/clean/<task>/<Model>_{robustness,std,se,drop}.pkl`;
  - `result/criteria/clean/<task>.csv`;
  - `result/repeat_raw/<task>/<Model>_<condition>.npz`.
- Noise-trained branch: `--exp noise`, which evaluates only `base/gauss/salt`; use
  `--max-repeats 1` to match the archived single-repeat noise branch.

### 1.4 Main figures

```bash
python -m src.pipelines.plot_clean --task classification
python -m src.pipelines.plot_noise --task classification
python -m src.pipelines.plot_clean --task regression
python -m src.pipelines.plot_noise --task regression
python -m src.pipelines.plot_clean --task classification_full
```

- Code: `src/viz/clean_plots.py`, `src/viz/noise_plots.py`, `src/pipelines/plot_*.py`.
- Output: `figure/generated/clean/<task>/overall_*.pdf|png`, `facet_*.pdf|png`; the noise branch writes
  `figure/generated/noise/<task>/radar_*.pdf`, `noise_metric_*.pdf`.
- The exact PDF panels inserted into the manuscript are fixed in `figure/pdf/panels/` (classification,
  regression, heatmap, legends), generated by `src/viz/panels.py`, `panels_extra.py`,
  `panels_sscan.py`.

### 1.5 SE aggregation and heatmap

```bash
python -m src.eval.aggregate
python -m src.eval.se_heatmap
```

- Code: `src/eval/aggregate.py`, `src/eval/se_heatmap.py`.
- `se_heatmap` only reads the main-experiment `*_se.pkl`; it does not regenerate noise or refit probes.
- Output:
  - `result/standard_error/se_agg_by_layer.csv` (per-layer, per-condition covariance-aware SE);
  - `result/standard_error/{se_by_layer,se_summary,std_by_layer,std_summary}.csv`;
  - `figure/generated/standard_error/se_heatmap.pdf|png`, `std_heatmap.*`.
- Paper: Section 5.3.3, Figure `fig:std_heat`; the text reports ten repeats, SE of order 1e-3, and the 2.77 SE tie threshold.

### 1.6 Full ten-class CIFAR-10

> Runner: `src/pipelines/run_full_cifar10.py`

```bash
python -m src.data.build_dataset --dataset cifar10_full
python -m src.pipelines.run_full_cifar10 --models VGG-11 Res-18 ViT-8 Mix-8
python -m src.pipelines.run_full_cifar10 --skip-train --skip-data
```

- Purpose: check that the four-class subset is not driving the conclusion.
- Data/models: four networks retrained on the 50k full CIFAR-10; ten OVR facets.
- Output: `result/criteria/clean/classification_full/` (shared with the main experiment),
  `result/criteria/clean/classification_full/tidy/`; `figure/generated/clean/classification_full/`.
- Paper: Section 5.3.1, Table `tab:noi_cla_full`, Figure `fig:sub_cla_full`.

### 1.7 Weighted scores and rankings

> Code: `src/eval/scoring.py`, `src/eval/make_score_table.py`

```bash
python -m src.eval.scoring
python -m src.eval.make_score_table
```

- Purpose: compare equal weights with three “single-noise dominant” schemes (0.6/0.1/0.1/0.1/0.1).
- Input: main `result/criteria/clean/{classification,regression}`.
- Output: `result/scoring/{scores_wide,scores_long,ranking_diff,kendall_tau}.csv`,
  `score_table.tex`, `score_report.md`; `figure/generated/scoring/rank_bump.png`.
- Paper: Section 6 (Application Example), Table `tab:score`.

### 1.8 Reliability with noise-trained networks

> No separate code directory; reuses the main pipeline (`--exp noise`).

Re-evaluate networks trained with Gaussian + salt-pepper noise and compare clean-trained and
noise-trained criteria:

```bash
python -m src.pipelines.run_train --task classification --model VGG-11 --exp noise --noise-aug
python -m src.pipelines.run_probe_eval --task classification --model VGG-11 --exp noise --max-repeats 1
python -m src.pipelines.plot_noise --task classification
python -m src.pipelines.plot_noise --task regression
```

- Inputs: `model/<task>/noise_trained/`, `result/probe/noise/`, `result/criteria/noise/`.
- Outputs: `figure/generated/noise/<task>/radar_*.pdf`, `noise_metric_*.pdf`.
- Paper: Section 5.4.1, Figures `fig:comp_acc`, `fig:comp_acc_s1/s2`.

## 2. Add-on experiments (grouped by paper subsubsection)

All add-ons live in `src/add_exp/` and are grouped by the paper structure; experiments from the same subsubsection share a folder, e.g. the sampling and noise stability experiments of 5.2.2 are both under `probe_stability/`.

### 5.2.1 Probe construction cost

> Folder: `src/add_exp/probe_efficiency/`

```bash
python -m src.add_exp.common.features
python -m src.add_exp.probe_efficiency.benchmark_ovr
python -m src.add_exp.probe_efficiency.bench_one_ovr --site VGG_L3 --method diag --repeats 3 \
    --out /tmp/VGG_L3_diag.json
```

- Purpose: wall-clock time and peak memory of Exa / Diag / BGD / SGD / LS.
- Input: `dataset/features/features4_{VGG-11,Res-18}.npz`.
- Output: `result/add_exp/probe_efficiency/benchmark_ovr.json`, `bench_ovr/*.json`,
  `tidy/04_probe_cost.csv`.
- Paper: Table `tab:exp2` (seven sites; `RES_L3` is kept in the JSON/CSV for completeness).

### 5.2.2 Weight stability under subsampling

> Folder: `src/add_exp/probe_stability/weight_vs_samples/`

```bash
python -m src.add_exp.common.features
python -m src.add_exp.probe_stability.weight_vs_samples.compute_stability --tag 8sites_10rep
python -m src.add_exp.probe_stability.weight_vs_samples.plot_stability
```

- Purpose: ten independent stratified subsamples per `(site, n/d, mode)`; report the 45 pairwise
  cosines among the ten weights.
- Output: `result/add_exp/probe_stability/weight_vs_samples/small_n_stability_8sites_10rep.json`,
  `*_by_ratio.csv`, `*_summary.csv`;
  `figure/generated/add_exp/probe_stability/weight_vs_samples/exp3_weight_stability_pairwise.pdf|png`.
- Paper: Figure `fig:weight_vs_samples` (2×4 panels in `figure/pdf/panels/figure2/`).

### 5.2.2 Weight stability under feature noise

> Folder: `src/add_exp/probe_stability/weight_vs_noise/`

```bash
python -m src.add_exp.common.features
python -m src.add_exp.probe_stability.weight_vs_noise.compute_stability --tag 8sites_10draws
python -m src.add_exp.probe_stability.weight_vs_noise.plot_stability
```

- Purpose: for each `rho ∈ {1,2,5,10,20,50,100,200}%`, draw ten independent feature-noise
  realisations and report pairwise weight cosines; `cos(w_noisy,w_clean)` is kept as an audit line.
- Output: `result/add_exp/probe_stability/weight_vs_noise/noise_pairwise_stability_8sites_10draws.json`,
  `*_by_rho.csv`, `*_summary.csv`;
  `figure/generated/add_exp/probe_stability/weight_vs_noise/exp3_noise_pairwise_stability.*`, `noise_vs_clean_supplementary.*`.
- Paper: Figure `fig:weight_vs_noise` (panels in `figure/pdf/panels/figure3/`).

### 5.4.2 Rotated noise direction: MD-LP vs CKA / SVCCA / t-SNE

> Folder: `src/add_exp/similarity_comparison/`

```bash
python -m src.add_exp.common.features
python -m src.add_exp.similarity_comparison.compute_rotation
python -m src.add_exp.similarity_comparison.plot_rotation
```

- Purpose: keep the noise amplitude fixed and rotate its direction `theta` from 0° to 90°; correlate
  each criterion with `theta` (Spearman).
- Sites: `VGG_L3/L9`, `RES_L3/L8`.
- Output: `result/add_exp/similarity_comparison/real_rot_insample.json`, `tidy/08_rotation_spearman.csv`;
  `figure/generated/add_exp/similarity_comparison/real_rot_insample.png`, `fig_rot_schematic.*`.
- Paper: Table `tab:rot-noise-corr` and the schematic figure.

### 5.4.3 Sensitivity to the susceptible-sample ratio s

> Folder: `src/add_exp/s_sensitivity/`

```bash
python -m src.add_exp.s_sensitivity.scan_s --repeats 10
python -m src.add_exp.s_sensitivity.make_figure
python -m src.add_exp.s_sensitivity.make_rank_table
python -m src.add_exp.s_sensitivity.make_rank_table_alt
```

- Purpose: generalise the `s=0.2` selection rule to `s=0.4/0.6/0.8` and compare absolute criteria and
  network rankings.
- Input: main probes (`result/probe/clean/classification/<Model>/`) and noise; `s=0.2` is taken from
  the main results.
- Output: `result/add_exp/s_sensitivity/noise_s_rank_maincal{,_full}.json`,
  `s_rank_table_maincal.tex`, `rank_s_own_maincal.tex`, `tidy/09_s_scan_*.csv`;
  `figure/generated/add_exp/s_sensitivity/s_scan_classification_maincal.pdf|png`.
- Paper: Table `tab:rank_s_own`, Figure `fig:s_scan`.

## 4. Suggested running order

1. Main experiment: train (or use the provided weights) → noise → probe evaluation → figures → SE.
2. 5.3.1 (full CIFAR-10) can run in parallel with the main experiment.
3. probe_efficiency / probe_stability / similarity_comparison share `features4_*.npz`; run `python -m src.add_exp.common.features` once.
4. scoring and s_sensitivity only need the main results and can run afterwards.
